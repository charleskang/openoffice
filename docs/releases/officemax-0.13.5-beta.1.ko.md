오피스Max Mac 시험판의 업데이트 경로를 준비했습니다. Windows에서 추가한 기능과 Mac용 LaTeX PDF 글꼴 수정을 그대로 포함합니다.

## 새로 들어간 것

- GitHub Releases에서 Mac 설치 파일을 받을 수 있습니다.
- 설정에서 베타 버전 채널을 선택하면 이후 Mac 시험판을 확인할 수 있습니다. 새 버전 안내에서 다운로드 페이지를 열 수 있습니다.

## 고친 것

- 일반 베타 업데이트 경로에서 인식되도록 시험판 버전을 `0.13.5-beta.1`로 맞췄습니다.

## 알려진 한계

- Apple Developer ID 서명·공증 전 단계입니다. 업데이트 알림을 받은 뒤 새 앱을 직접 교체해야 합니다.
- M5를 포함한 Apple Silicon용이며, 이번 릴리스에는 Windows·Intel Mac·Linux 설치 파일을 올리지 않습니다.

## 설치

- Mac: `OfficeMax-0.13.5-beta.1-arm64.dmg`를 열고 앱을 응용 프로그램 폴더로 옮기세요. 기존 앱을 교체하기 전에는 작업을 저장하고 종료하세요.
- 기존 시험판: 설정 → 정보 → 업데이트 채널에서 베타 버전을 선택한 뒤 도움말 → 업데이트 확인을 누르세요.
