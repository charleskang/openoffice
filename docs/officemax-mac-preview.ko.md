# 오피스Max M5 시험판

Apple Silicon용 arm64 앱입니다. 최신 Windows 작업 소스를 같은 커밋에서 전체 빌드하며, GPT API 연결, 작업 중심 홈과 아이콘, LaTeX ZIP 프로젝트·편집·PDF 미리보기·AI 오류 수정, 발표의 수식·차트 및 내장 스프레드시트 편집, 전체 시트 PDF 저장을 포함합니다.

## 설치

1. `OfficeMax-0.13.4-mac-preview.2-arm64.dmg`를 맥북에서 엽니다.
2. `OfficeMax.app`을 응용 프로그램 폴더로 복사합니다.
3. 디스크 이미지를 추출한 뒤 응용 프로그램 폴더의 앱을 실행합니다.
4. macOS가 개발자를 확인할 수 없다고 막으면, 이 빌드의 출처와 체크섬을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 열기를 허용합니다. 보안 기능 전체를 끄지 않습니다.
5. 설정에서 OpenAI API 연결을 지정합니다. API 키나 Windows 사용자 설정은 설치파일에 들어 있지 않습니다.

Node.js·Rust·Xcode·TeX 배포판을 별도로 설치할 필요가 없습니다. Tectonic을 포함하며 첫 LaTeX 컴파일 때 필요한 TeX 지원 파일을 내려받을 수 있습니다. 문서 소스와 PDF는 로컬에서 처리하고 GPT 제안 요청을 선택했을 때만 관련 소스와 오류 정보를 설정된 OpenAI API로 보냅니다.

## 검증과 제한

이 시험판은 GitHub의 Apple Silicon Mac에서 빌드하고 자동 검사합니다. `SOURCE-COMMIT.txt`, `SMOKE-RESULT.json`, `SHA256SUMS.txt`를 함께 제공합니다. M5 Pro의 macOS 27.0.1에서의 직접 사용 검증은 별도로 필요합니다.

Apple Developer ID 서명·공증을 하지 않은 시험판입니다. 실행에 필요한 임시 서명은 포함하지만 자동 설치 업데이트는 제공하지 않습니다. 다음 시험판은 앱을 종료하고 새 앱 전체를 교체하며 문서와 사용자 설정은 유지합니다.

엑셀 전체 PDF는 파일 → PDF 내보내기 → 전체 통합 문서로 저장합니다. 보이는 시트를 탭 순서대로 넣고, 숨긴 시트와 내용·그림·명시적 인쇄 영역이 없는 빈 시트는 제외합니다.
