# 오피스Max 오류 로그

Windows와 Mac에서 오류와 충돌 기록을 각 컴퓨터에 자동 저장합니다. 도움말 → **오류 로그 폴더 열기**에서 확인할 수 있습니다.

- Windows: `%APPDATA%\OfficeMax\diagnostics`
- Mac: `~/Library/Application Support/OfficeMax/diagnostics`

`error-시각-식별자.json` 파일에는 발생 시각, 앱·운영체제 버전, 오류 종류·코드, 편집기 종류와 메모리 상태를 기록합니다. JavaScript 오류는 앱 내부 코드의 상대 위치와 줄·열 번호도 남깁니다. 최근 보고서 40개를 보관하며 같은 오류가 반복되면 1분 동안 추가 기록을 제한합니다.

기록 대상은 메인 프로세스 예외와 처리되지 않은 비동기 오류, 편집기·GPU·보조 프로세스 충돌, 화면의 오류와 응답 없음입니다. 초기화 중 오류도 가능한 이른 시점부터 기록합니다. 전체 앱이 강제로 종료돼 마지막 오류를 쓰지 못한 경우에는 다음 실행에서 이전 실행이 정상 종료되지 않았다는 보고서를 만듭니다. 이 보고서만으로 충돌·강제 종료·전원 문제를 구분하지는 않습니다. 첫 설치 전의 종료는 소급 기록하지 않습니다.

문서 본문, 문서 이름·경로, API 키, 오류 메시지 원문이나 전체 메모리 덤프는 저장하지 않습니다. 보고서는 자동 전송하지 않습니다. 문제를 확인할 때 해당 시각의 JSON 파일을 직접 전달하면 됩니다. 기존 데이터 폴더의 짧은 요약 `crash-log.jsonl`도 유지합니다.
